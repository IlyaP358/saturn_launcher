**Saturn Launcher** is a lightweight, fast, and easy-to-use console-based Minecraft launcher.

> [!NOTE]
> **Early Development**: This project is currently in early development. All versions (CLI and GUI) are fully functional but may contain bugs and imperfections. For any ideas, suggestions, or bug reports, please create an issue on [GitHub](https://github.com/IlyaP358/saturn_launcher/issues) or contact via email: illia.pukalov@teleinformatika.eu.

## Features

- **Fast & Lightweight**: Optimized for performance with minimal resource usage.
- **Cross-Platform**: Runs on Windows and Linux (macOS support planned).
- **User Friendly**: Simple command-line interface with rich text formatting.

## Quick Start

For detailed installation instructions, see [Installation Guide](docs/installation.md).

Pre-compiled versions are available in the [Releases](https://github.com/IlyaP358/saturn_launcher/releases) tab.

To get started quickly:

- <img src="https://raw.githubusercontent.com/IlyaP358/saturn-web/main/windows_logo.png" width="20" alt="Windows"> **Windows**: Download `saturn_win.exe` from [Releases](https://github.com/IlyaP358/saturn_launcher/releases) and run it.
- <img src="https://raw.githubusercontent.com/IlyaP358/saturn-web/main/linux_logo.png" width="20" alt="Linux"> **Linux**: Download `saturn_linux` from [Releases](https://github.com/IlyaP358/saturn_launcher/releases), make executable, and run.
